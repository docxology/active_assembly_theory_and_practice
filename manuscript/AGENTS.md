# Manuscript Instructions

- Use Pandoc citations such as `[@heins2022pymdp]`.
- Use labelled cross-references such as `[@fig:posterior-beliefs]`.
- Keep computed values as `{{TOKEN}}` variables generated by
  `src/manuscript_variables.py`.
- Figures must live under `output/figures/` and be referenced as
  `../output/figures/<name>.png` after token hydration.
