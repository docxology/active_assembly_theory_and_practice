# Active Assembly Theory and Practice manuscript

Start with the [abstract](00_abstract.md), [methodology](02_methodology.md)
and [validation](05_validation.md) for the bounded assembly-language fixture
experiments. The numbered Markdown files are the editable source. Keep their
[render configuration](config.yaml), [preamble](preamble.md), [bibliography](references.bib)
and [cover](assets/active_assembly_cover.png) with the sections.

Follow the [rendering guide](../document_rendering.md) to generate the model
receipts and figures, resolve manuscript variables and build the configured
formats. Hydration writes copies to `output/manuscript/`. Treat the checked-in
examples under `data/` and `figures/` as historical illustrations. Current
figures and manuscript claims are bound to fresh producer receipts.
