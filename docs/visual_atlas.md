# Source-bound visual atlas

The visual atlas is the canonical metadata and accessibility boundary for the
technical-monograph figures. It is produced by `src.figure_contract` and is
consumed by the manuscript-variable producer, the sibling template, the DOCX
and PDF validators, and the offline HTML atlas. Plotting code may create pixels,
but it does not own the caption, source note, status semantics, or alternative
text.

## Contract

Every substantive visual has one `FigureSpec` with a stable identifier and
Pandoc label. The spec records its section and placement, analytical question,
descriptive title, population and sample hierarchy, split, metrics, uncertainty
method, missing/unseen/unsupported/unavailable semantics, evidence status,
claim identifiers, scholarship keys, producer revision, source-artifact paths,
and exact input hashes. It also records a visible caption, short alternative
text, long description, slide caption, raster/vector output paths, and
programmatic visual-QA results.

The current figure set is defined by the live registry and `build_figure_specs`. Nine narrative figures
are generated by `src.visual_atlas`; the established diagnostic figures remain
in the same registry and are available in the appendix/atlas. The cover is a
separate document asset and is not counted as a substantive figure.

Statuses describe evidence, not aesthetics. A formal or computational status
does not become an empirical population result; `underpowered`, `unavailable`,
`unsupported`, `excluded`, `blocked_external`, `not_yet_observed`, and
`unresolved` remain visible. No figure producer may replace such a value with a
numeric zero merely to complete a plot.

## Generated surfaces

```text
output/figures/<figure_id>.png
output/figures/vector/<figure_id>.svg
output/figures/vector/<figure_id>.pdf
output/data/figure_registry.json
output/figures/figure_registry.json
output/figures/README.md
output/figure_atlas/index.html
output/figure_atlas/figure_registry.json
```

The PNG is the compatibility input for DOCX/PDF rendering. Native SVG/PDF
exports are used for the nine narrative figures and explicit raster fallbacks are
used only for compatibility plots whose producer exposes a raster path but no
native vector path. The fallback remains source-bound to the same raster hash
and is labelled in the visual-QA fields; it is not presented as a native vector
chart.

The HTML atlas is semantic and offline. Each entry has one `figure`, one
`figcaption`, a short image alternative, a visible caption, an expandable long
description, source-artifact digests, status metadata, and links to the vector
companions. Dense matrices and status figures include their exact data/status
table. The atlas has no remote scripts, fonts, CSS, chart runtime, or network
request.

## Producer and audit commands

From the project checkout:

```bash
uv run python scripts/run_scientific_program.py generate-figures \
  --formats png svg pdf atlas
uv run python scripts/run_scientific_program.py audit-figures
uv run python scripts/z_generate_manuscript_variables.py
```

Hydration alone does not export a document. The native export and post-render
sequence are maintained in [document rendering](document_rendering.md).

The programmatic API is:

```python
from pathlib import Path
from src.figure_contract import (
    build_figure_specs,
    validate_figure_bundle,
    write_figure_atlas,
    write_figure_bundle,
)

root = Path.cwd() / "output"
specs = build_figure_specs(root)
write_figure_bundle(root, formats={"png", "svg", "pdf", "atlas"})
write_figure_atlas(root, specs)
errors = validate_figure_bundle(root)
```

Manuscript source uses canonical figure caption/path tokens for embedded
figures. Compatibility path tokens remain available for older callers. Metadata
for figures used only in the appendix or atlas is emitted as an explicit
atlas-only variable rather than being treated as an unexplained unused value.

## Caption and accessibility policy

Main captions are normally 120–220 words and may reach 260 words for complex
multi-panel visuals. They identify what is encoded, the population and
hierarchical denominator, split, model/baseline definitions, interval or exact
enumeration method, units, evidence status, and the conclusion that is not
licensed. Short alternatives are concise descriptions of the visual structure,
not a replacement for the scientific caption. Long descriptions explain panel
relationships, status semantics, and the meaning of absence for a reader using
the atlas without visual access. Slide captions remain short while the full
source-bound caption and long description stay in the registry.

Color is never the only status channel. Hatching, marker shape, line style,
direct text, and table values reinforce categories and signed quantities. A
gray-scale rendering must retain the essential distinction. Unavailable,
unsupported, and not-observed cells use text or em dashes; a true measured zero
is shown only when zero is part of the receipt. Figures are reviewed at native
resolution, page scale, and contact-sheet scale for clipping, label legibility,
caption attachment, contrast, and misleading visual emphasis.

## Source closure

The canonical registry is rebuilt after receipts and before manuscript
hydration. A visual fails audit if a required source artifact is absent, its
hash is stale, the PNG is blank, a vector file is unparsable, metadata is
incomplete, the atlas count differs from the registry, or a caption contains a
status-to-zero substitution. The registry is also checked against the template
projection and the post-render DOCX/PDF media and tag-tree receipts. A passing
visual gate means that the visual is source-bound and accessible as generated;
it does not promote a blocked scientific result or substitute for peer review.
